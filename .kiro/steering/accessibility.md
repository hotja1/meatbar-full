# Доступность (WCAG 2.2 AA)

Основа — WCAG 2.2 уровень AA, рекомендации MDN и Nielsen Norman Group. Полная валидация требует ручного аудита с assistive technologies и экспертной проверки; в коде соблюдаем правила ниже.

## Контраст

- Обычный текст ≥ 4.5:1 к фону.
- Крупный текст (≥ 18 pt или 14 pt bold) ≥ 3:1.
- UI-элементы и графические контролы ≥ 3:1.
- Серый `--muted` на бежевом `--bone` — проверять отдельно.

## Клавиатура

- Каждый интерактив достижим через Tab.
- Порядок логический (не DOM-скачки).
- `:focus-visible` стиль обязателен: `outline: 2px solid var(--brass); outline-offset: 3px;`. Не убирать `outline` без замены.
- `Esc` закрывает модалки (`BookingDialog`, `CartDrawer`, `SideNav`).
- `Enter` / `Space` активируют кнопки.
- Внутри модалок — focus trap (фокус не уходит в фон).

## ARIA и семантика

- Предпочитать нативные теги: `<button>`, `<a>`, `<dialog>`, `<form>`, `<label>`.
- Если используется не-нативный элемент как кнопка: `role="button"` + `tabindex="0"` + обработчики клавиш.
- Модалки: `<dialog>` (HTML5) с `aria-labelledby` / `aria-describedby`.
- Живые регионы: `aria-live="polite"` для тостов, `aria-live="assertive"` для ошибок.
- Иконки без текста: `aria-label` на родителе.
- Декоративные SVG: `aria-hidden="true"`.

## Размер тач-целей

- Мобильные кнопки ≥ 44×44 px (Apple HIG) или ≥ 48×48 px (Material). Делаем 44 как минимум.
- Между соседними тач-целями ≥ 8 px.

## Motion-guards

- `@media (prefers-reduced-motion: reduce)` — отключает всё, что не является прогрессом задачи (декоративные анимации, parallax, canvas-эффекты).
- Canvas-компоненты (EmberField, AnimatedFire, DriftingClouds, FireText) проверяют этот media query в JS и не запускают rAF.

## Формы

- Каждый `<input>` имеет связанный `<label>`.
- Ошибка: `aria-invalid="true"` + связанный `aria-describedby` с текстом ошибки.
- Не использовать только цвет для передачи ошибки (добавлять иконку и текст).
- Маска телефона не должна мешать вставке (paste).

## Текст

- Язык: `<html lang="ru">`. Для английских вкраплений — `lang="en"` на элементе.
- Абзацы не более 80 символов в строке (читаемость).
- Русский текст: `word-break: keep-all; hyphens: none`.
- Не использовать `text-transform: uppercase` на длинных русских строках — ломает screen reader и читается плохо.

## Изображения и медиа

- `alt` обязательный, описательный: `alt="Стейк рибай в Мясо Баре, Нижневартовск"`.
- Декоративные картинки: `alt=""`.
- Видео (hero-reel): без звука, не играет автоматически со звуком. Постер обязательный.
- Если звук появится (AmbientAudio) — кнопка выкл/вкл, `localStorage` флаг, по умолчанию off.

## Типичные ошибки в проекте

- `<div onClick>` вместо `<button>` → не клавиатурно.
- Пустой `alt` на значимой картинке.
- `outline: none` на фокус-стиле без альтернативы.
- Серый `--muted` на тёмном `--coal` — может упасть ниже 4.5:1, проверять.

## Инструменты

- DevTools → Lighthouse → Accessibility audit.
- `axe-core` расширение для DevTools.
- Запускать клавиатурный тест: отключить мышь, пройти бронирование с Tab/Enter.
