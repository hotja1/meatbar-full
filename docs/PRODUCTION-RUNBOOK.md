# PRODUCTION-RUNBOOK.md

Дата: 2026-05-10  
Проект: «Мясо Бар» (Нижневартовск)

## 1) Предрелизный прогон (обязательно)

В корне `frontend/`:

1. `npm run guard:mojibake`
2. `npm run lint`
3. `npm run build`
4. `npm run perf:budgets`

Если любой шаг упал — релиз не делаем.

## 2) Быстрый smoke-check после выката

1. Открыть главную страницу.
2. Проверить, что кнопка `Бронь` ведёт в `#booking`.
3. Проверить загрузку карты столов и popup при наведении.
4. Проверить отправку тестовой брони.
5. Проверить `/api/health` (должно быть `ok: true`).
6. Проверить `robots.txt` и `sitemap.xml` на прод-домене.

## 3) Откат (rollback)

Если после выката деградация:

1. Вернуть предыдущий релиз фронта (`backend/public`/CDN-версию).
2. Перезапустить backend-процесс.
3. Повторить smoke-check.
4. Зафиксировать инцидент и причину.

## 4) Восстановление SQLite из бэкапа

1. Остановить backend.
2. Сделать копию текущего `backend/data/*.db`.
3. Подменить файл БД на последний стабильный бэкап.
4. Запустить backend.
5. Проверить `/api/health`, брони, заказы, админку.

## 5) Минимальный мониторинг

Должны контролироваться:

1. HTTP доступность главной страницы.
2. Доступность `/api/health`.
3. Ошибки backend в логах.
4. Динамика web-vitals (`/api/rum`).

## 6) Инциденты по SEO

Если пропали страницы из индекса:

1. Проверить `robots.txt` на прод-домене.
2. Проверить `sitemap.xml` на прод-домене.
3. Проверить canonical/`og:url` в HTML главной.
4. Проверить `X-Robots-Tag` для `/admin/*` (должно быть `noindex`).

## 7) Секреты и интеграции

1. Не хранить ключи в репозитории.
2. Все токены только через env.
3. Перед релизом проверить, что включены нужные интеграции (Telegram/VK/YooKassa/SMS) и отключены неготовые.
